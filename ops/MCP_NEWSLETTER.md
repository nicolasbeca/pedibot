**Asunto:** MCP server: children's health answers from published guidelines

Hi,

I'd like to submit a remote MCP server in case it's useful for an issue.

PediBot answers parents' questions about children's health using only published paediatric
guidelines (WHO, NHS, CDC, national ministries and paediatric societies), and every answer says
which document it comes from. The MCP server exposes the same tools the website uses:
paracetamol and ibuprofen doses by weight, the vaccination schedule of 75 countries, WHO growth
percentiles, oral rehydration, a check of symptoms against 96 fixed warning-sign rules, and the
sourced Q&A itself, in eight languages.

The numbers never come from a language model: doses, schedules and percentiles are read from
fixed tables, and when there's no source the tool says so instead of guessing. It's free,
streamable HTTP, no key and no sign-up:

https://pedibot.xyz/mcp

It's in the official registry as xyz.pedibot/pedibot, and the site is https://pedibot.xyz
